# Project Instructions

## Project Overview
Bike aero analyser. User submits a .fit file, it is parsed, gps data is displayed. Other data is graphed below. 
The user can select a section (incl laps), and analyse it using parameters (weight, crr, drivetrain losses etc). A cda is calculated and stored.

## Stack
- Language : Python (backend, Flask), Javascript
- Framework: Flask
- Database: Some SQL
- Styling: CSS
